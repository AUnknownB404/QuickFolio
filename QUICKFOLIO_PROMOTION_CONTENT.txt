quickFolio — Project Promotion Content

LINKEDIN DESCRIPTION

I built **quickFolio**, a web application that helps people create and publish a professional portfolio without building a website from scratch. Users can choose from ready-made templates, add and manage their content, upload images and documents, and publish a portfolio at a public link. The app also supports Google Forms contact forms and downloadable static ZIP exports.

Built with **Laravel 12, PHP, Vue 3, TypeScript, Inertia.js, Tailwind CSS, and Cloudflare R2**.

CV PROJECT ENTRY — ATS-FRIENDLY

**quickFolio | Full-Stack Portfolio Builder**  
**Technologies:** PHP 8.2+, Laravel 12, Vue 3, TypeScript, Inertia.js, Tailwind CSS, SQLite, Cloudflare R2

- Developed a full-stack portfolio-building web application with Laravel and Vue 3, enabling users to select templates, create and edit portfolio content, and publish portfolios to public URLs.
- Implemented portfolio management features including image and document uploads, template switching, Google Forms contact form configuration, and static ZIP export.
- Built a reusable template marketplace and administration tools, using TypeScript, Inertia.js, Tailwind CSS, and Cloudflare R2 for portfolio and template media storage.
